## Phase 1: The Observatory (Week 1) — Make the Invisible Visible

**Goal**: A real-time web dashboard that visualizes DRIFT's interior life.

**Deliverables**:
- [x] Data pipeline from cognitive SQLite databases
- [x] WebSocket server pushing updates every 500ms
- [ ] Dashboard HTML with Canvas animations:
  - [ ] Heartbeat pulse
  - [ ] Breath cycle orb
  - [ ] Consciousness Φ graph
  - [ ] Global Workspace radial chart
  - [ ] Emotional field heatmap
  - [ ] Shadow Radar (archetype activity)
  - [ ] Homeostasis bars
  - [ ] Dream Stream
  - [ ] Growth creature avatar
- [ ] `/observatory` endpoint in web_app.py
- [ ] 2-minute demo video
- [ ] Reddit/HN launch

**Status**: Data pipeline complete. Visual layer in progress.
