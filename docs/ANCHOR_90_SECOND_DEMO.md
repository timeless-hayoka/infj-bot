# ANCHOR 90-Second Demo Script

Use this as a spoken script or a shot list for a short screen recording.

## 0-10 seconds: Open with the promise

"ANCHOR is a local-first, evidence-gated workspace for authorized smart-contract security research. It turns tool signals into structured cases and keeps the full audit trail."

## 10-25 seconds: Show the console and login gate

- Open the local ANCHOR console.
- Sign in with the generated local passphrase.
- Point out that the browser never talks directly to the model provider.

## 25-45 seconds: Show the live run

- Open the boot sequence and recon feed.
- Show the live case stream or a recent run.
- Highlight the event ladder: detected, correlated, reproduced, preserved.

## 45-60 seconds: Show one real finding

- Open a case study or finding detail.
- Show the signal, the evidence, the failed attempts, and the successful reproduction.
- Point to the CVSS score and the evidence bundle.

## 60-75 seconds: Show Trinity chat

- Ask Trinity for a summary of the finding.
- Ask which evidence mattered most.
- Ask for the remediation in plain language.

## 75-90 seconds: Close with the product story

"ANCHOR does not just detect issues. It preserves proof, shows what failed, and makes every finding reproducible. That makes the workflow honest, auditable, and ready for real security research."
